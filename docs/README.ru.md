Платформа для практики английского и учебного исследования. Интерфейс поддерживает **English / Русский / Қазақша**; задания остаются на английском.

Файлы `.md` можно читать прямо в GitHub или открыть в VS Code: **Ctrl+Shift+V** на Windows/Linux, **⌘ Shift V** на macOS включает удобный предпросмотр. Начните с установки, затем выберите руководство своей роли.

## Самый короткий путь

Если учитель уже прислал работающую ссылку, ученику достаточно открыть её в браузере. Устанавливать Node.js и Docker не нужно.

Для самостоятельного запуска установите Node.js **24 LTS**, распакуйте архив проекта, откройте терминал в папке с `package.json` и выполните:

```sh
npm ci
npm run setup:demo
npm run dev:local
```

Откройте **http://localhost:3000**. Аккаунт и API-ключи не нужны. Это готовый режим обучения с демо-помощником; он не сохраняет результаты исследования.

Для полного локального режима с сохранением сначала установите и запустите Docker. Если демо-сервер уже работает, остановите его через **Ctrl+C**, затем в той же папке:

```sh
npm run setup:local
npm run db:check
npm run dev:local
```

Подробности, повторный запуск и решение ошибок находятся в [инструкции установки](INSTALLATION.ru.md). Локальные ключи определяются автоматически; рабочие облачные секреты не входят в учебный архив.

## Какая это версия

Документация относится к версии с shadcn/ui, тремя языками, подготовленным демо-помощником и командой `setup:local`. Минимальный Node.js — 22.13; рекомендуемая и проверенная ветка — 24. Supabase CLI закреплена на **2.116.0**, версии остальных пакетов — в `package-lock.json`.

Логинов `student`/`teacher` и личных кабинетов в приложении нет. Для учебного исследования браузер получает анонимный идентификатор. Учительская роль описывает способ использования платформы, а не отдельный уровень доступа в интерфейсе.
